.gitignore = Datei in der wir alle Ordner und Dateien hinterlegen die wir nicht auf GitHub veröffentlichen wollen

    - DS_Store in der .gitignore ist ein Standardverzeichnis was bei Mac Nutzern automatisch erstellt wird
    - Bilder wollen wir generell vermeiden auf GitHub zu veröffentlichen (da wir den push und pull Prozess möglichst schnell halten wollen, in dem Fall wäre es nicht der Rede wert)
    - .vscode ist ein Ordner von VSCode der persönliche Editor Einstellungen als auch nützliche Projektkonfigurationen enthalten kann. Das ist also Teamabhängig ob der Ordner ignoriert wird oder nicht

.gitkeep = Datei die wir nutzen um leere Ordner auf GitHub zu veröffentlichen (ohne werden leere Ordner nicht veröffentlich)
